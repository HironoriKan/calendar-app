# カレンダー日程調整アプリ

React と Tailwind CSS で構築された、シンプルなカレンダー日程調整アプリです。

## 機能

- 週単位でのカレンダー表示
- 日時の選択と解除
- 選択した日時のテキスト生成
- モバイル対応レイアウト
